The extracted palette is a permanent strip along the bottom edge rather than something revealed on hover. It is what the library searches on, so hiding it would hide the index — and at 10px it reads as a colour signature without competing with the plate above it.

Notes are set in the serif italic. Everything a person wrote looks handwritten against the machine-set filename and dimensions directly above, which is the whole reason the system carries two families.

No grayscale. The system's image treatment is deliberately none: this library is searched by colour, so desaturating the plates would break the tool it dresses.
