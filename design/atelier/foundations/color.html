Every hue in the system sits between 20° and 60° — paper, olive, clay. That is deliberate: this palette dresses a library of other people's photographs, and a saturated or cool interface colour competes with the imagery for the eye. Clay is the only note allowed to raise its voice, and it is reserved for destructive actions and alerts.

Both ramps are generated on one shared lightness scale, so accent-600 and neutral-600 carry the same visual weight and can be swapped without re-checking contrast.
