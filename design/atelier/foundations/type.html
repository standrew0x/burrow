Two families doing two jobs. Fraunces carries anything a person wrote — headings, captions, and the notes attached to a reference — so authored text is visually distinct from generated text at a glance. Instrument Sans carries the interface: labels, buttons, counts.

The rule that keeps it honest: if a machine produced the string, it is not set in the serif. Filenames, dimensions and hashes go to the mono face; everything the library computed goes to the sans.
